Je veux créer une application mobile React Native (Expo) appelée CAARCO — une application de transport de marchandises et déménagement à la demande, similaire à Uber, pour le Cameroun.

═══════════════════════════════════════════════════════
1. CONTEXTE MÉTIER
═══════════════════════════════════════════════════════

CAARCO met en relation des clients qui ont besoin de transporter des biens
(colis, meubles, marchandises) avec des transporteurs locaux au Cameroun.

3 rôles utilisateurs :
- CLIENT : demande une course, suit en temps réel, paie en XAF
- TRANSPORTEUR : reçoit les demandes, accepte/refuse, navigue jusqu'au client
- ADMINISTRATEUR : gère les utilisateurs, les litiges, les statistiques

Formule de calcul du prix (en Francs CFA) :
  prix = 500 + (distance_km × tarif_vehicule)
  Tarifs : moto=150, voiture=250, camionnette=400, camion=700 (XAF/km)

2. STACK TECHNIQUE
═══════════════════════════════════════════════════════

- Framework    : React Native avec Expo SDK (dernière version stable)
- Navigation   : React Navigation v6 (Stack + Bottom Tabs par rôle)
- Backend      : Supabase (base de données + auth + temps réel)
- GPS/Cartes   : react-native-maps + expo-location
- Polices      : expo-google-fonts (Marcellus, Plus Jakarta Sans, JetBrains Mono)
- État         : React Context API (pas de Redux pour simplifier)
- Paiements    : prévu pour Orange Money / MTN MoMo (phase 2)

5. BASE DE DONNÉES SUPABASE — TABLES À CRÉER
═══════════════════════════════════════════════════════

Crée ces 5 tables dans Supabase avec exactement ces colonnes :

TABLE users :
  id            uuid PRIMARY KEY (auth.uid)
  nom           text NOT NULL
  telephone     text UNIQUE NOT NULL
  role          text NOT NULL CHECK (role IN ('client','transporteur','admin'))
  photo_url     text
  statut        text DEFAULT 'actif'
  created_at    timestamptz DEFAULT now()

TABLE vehicules :
  id               uuid PRIMARY KEY DEFAULT gen_random_uuid()
  transporteur_id  uuid REFERENCES users(id)
  type             text NOT NULL CHECK (type IN ('moto','voiture','camionnette','camion'))
  immatriculation  text UNIQUE NOT NULL
  capacite_kg      int
  photo_url        text
  valide           boolean DEFAULT false

TABLE courses :
  id               uuid PRIMARY KEY DEFAULT gen_random_uuid()
  client_id        uuid REFERENCES users(id)
  transporteur_id  uuid REFERENCES users(id)
  depart_adresse   text NOT NULL
  depart_lat       float8
  depart_lng       float8
  arrivee_adresse  text NOT NULL
  arrivee_lat      float8
  arrivee_lng      float8
  type_vehicule    text NOT NULL
  distance_km      float8
  prix_fcfa        int
  statut           text DEFAULT 'en_attente'
                     CHECK (statut IN ('en_attente','acceptee','en_route','livree','annulee'))
  created_at       timestamptz DEFAULT now()
  updated_at       timestamptz DEFAULT now()

TABLE avis :
  id               uuid PRIMARY KEY DEFAULT gen_random_uuid()
  course_id        uuid REFERENCES courses(id)
  auteur_id        uuid REFERENCES users(id)
  note             int CHECK (note BETWEEN 1 AND 5)
  commentaire      text
  created_at       timestamptz DEFAULT now()

TABLE paiements :
  id               uuid PRIMARY KEY DEFAULT gen_random_uuid()
  course_id        uuid REFERENCES courses(id)
  montant_fcfa     int NOT NULL
  methode          text CHECK (methode IN ('especes','orange_money','mtn_momo'))
  statut           text DEFAULT 'en_attente'
  ref_transaction  text
  created_at       timestamptz DEFAULT now()

6. FORMULE DE PRIX — LOGIQUE EXACTE
═══════════════════════════════════════════════════════

// Fichier : src/services/prix.js
const TARIFS = {
  moto:        150,   // XAF par km
  voiture:     250,
  camionnette: 400,
  camion:      700,
};

const FRAIS_FIXES = 500; // XAF — frais de prise en charge

export function calculerPrix(distanceKm, typeVehicule) {
  const tarif = TARIFS[typeVehicule];
  if (!tarif) throw new Error('Type de véhicule invalide');
  const prix = Math.ceil(FRAIS_FIXES + (distanceKm * tarif));
  // Arrondi au 100 XAF supérieur pour la lisibilité
  return Math.ceil(prix / 100) * 100;
}

// Affichage : toujours avec le format "12 500 XAF" (espace comme séparateur de milliers)
export function formaterPrix(montant) {
  return montant.toLocaleString('fr-FR') + ' XAF';
}
